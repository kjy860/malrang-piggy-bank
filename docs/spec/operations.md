## 1. 테스트 계획

### 테스트 시나리오
1. **아이별 잔액 독립성 테스트**
   - Given: 두 명의 아이(A, B)가 등록되어 있다.
   - When: 아이 A의 저금통에만 5,000원을 입금한다.
   - Then: 아이 B의 잔액에는 영향을 주지 않고 아이 A의 잔액만 5,000원 증가한다.
2. **부모 모드 보안 테스트**
   - Given: 메인 화면에서 '부모 모드' 버튼을 눌러 인증 화면(`GET /parent/auth`)에 진입한다.
   - When: 틀린 4자리 비밀번호(`0000`)를 입력하고 확인을 누른다.
   - Then: 에러 팝업이 노출되고 대시보드 진입이 차단된다.
3. **목표 달성 축하 테스트**
   - Given: 목표 금액이 10,000원인 저금통에 현재 9,000원이 모여 있다.
   - When: 1,000원을 추가 입금하여 잔액이 10,000원이 된다.
   - Then: 목표 달성 상태(`is_achieved = true`)로 변경되며 축하 애니메이션이 발동한다.
