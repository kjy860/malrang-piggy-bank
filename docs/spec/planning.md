## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
5세, 9세 어린이들이 디지털 화면을 통해 저축하는 재미를 느끼고, 스스로 용돈을 관리하는 습관을 기를 수 있는 웹 기반 어린이 저금통 서비스입니다.

### 핵심 가치
- **직관성과 시각화**: 글을 온전히 모르는 5세 아이도 아이콘과 애니메이션으로 쉽게 이해할 수 있는 UI
- **성취감 부여**: 저축 목표 달성 시 축하 효과 제공
- **다자녀 관리**: 여러 명의 아이를 등록하고 개별 저금통을 각각 관리할 수 있는 구조
- **부모와 아이의 연동**: 부모 모드(4자리 비밀번호 보호)를 통해 전체 내역 관리 및 용돈 지급 가능
- **홈알바(집안일/심부름) 보상 시스템**: 아이가 집안일이나 심부름(홈알바)을 수행하고 보상금을 받아 저금통에 바로 저축할 수 있는 경제 교육 기능

## 2. 사용자와 사용 시나리오

### 주요 사용자
1. **아이 사용자 (5세, 9세 여자아이)**
   - 초기 아이 선택 화면에서 본인 이름을 터치하여 진입
   - 현재 잔액 확인, 용돈/저금 내역 조회, 목표 저축액 설정
   - 홈알바 목록 확인 및 완료 신청
2. **부모 사용자**
   - 4자리 비밀번호를 입력하여 부모 모드 진입
   - 아이 추가/삭제, 잔액 강제 조정, 전체 통계 확인
   - 홈알바 항목 등록 및 아이가 완료한 홈알바 승인/보상 지급

### 사용자 시나리오
- **Given**: 9세 아이가 자신의 저금통 화면에서 '홈알바' 메뉴에 진입하여 '방 청소하기 (+1,000원)' 항목을 본다.
- **When**: 아이가 '완료했어요!' 버튼을 눌러 부모님께 승인 요청을 보낸다.
- **Then**: 부모 모드에서 해당 알바가 승인 대기 상태로 표시되고, 부모가 승인하면 저금통 잔액에 1,000원이 자동 적립된다.

## 3. 기능 명세

### 기능 목록
| 기능 ID | 기능명 | 설명 | 대상 사용자 | 중요도 |
| --- | --- | --- | --- | --- |
| F-01 | 아이 선택 화면 | 등록된 아이 목록 프로필 카드(`name`, `avatar_emoji`)로 표시 및 선택 | 공통 | 상 |
| F-02 | 메인 저금통 화면 | 선택된 아이의 총 금액, 저금통 애니메이션, 목표 진행도 표시 | 아이 | 상 |
| F-03 | 입출금 기록 추가 | 돈을 넣거나 뺄 때 금액과 사유(이모지 선택) 기록 및 잔액 자동 반영 | 공통 | 상 |
| F-04 | 저축 목표 설정 | 사고 싶은 장난감 등 목표 이름과 목표 금액 설정 및 달성 여부 확인 | 아이/부모 | 중 |
| F-05 | 부모 관리자 모드 | 숫자 4자리 비밀번호(`1234`) 인증 후 아이 추가/삭제 및 전체 내역 강제 수정 | 부모 | 상 |
| F-06 | 홈알바(집안일) 관리 | 부모가 심부름/집안일 목록과 보상금액을 등록하고, 아이는 목록을 확인 후 수행 완료 요청 | 아이/부모 | 상 |
| F-07 | 홈알바 보상 적립 | 부모가 아이의 홈알바 완료를 승인하면 해당 금액이 아이의 저금통 잔액과 `transactions`에 자동 반영 | 부모/아이 | 상 |

### 수용 기준 (Given/When/Then)
- **F-03 입출금 수용 기준**
  - **Given**: 아이 저금통 화면에서 '돈 넣기' 버튼을 눌러 입금 화면(`GET /add?child_id=...`)에 진입해 있다.
  - **When**: 금액 `5000`원과 이모지 사유를 입력하고 '저장' 버튼을 누른다.
  - **Then**: `transactions` 테이블에 데이터가 추가되고, 해당 아이의 총 잔액이 5,000원 증가하며 메인 화면으로 돌아온다.
- **F-06/07 홈알바 완료 및 승인 수용 기준**
  - **Given**: 부모가 '설거지하기 (보상 2,000원)' 홈알바를 등록해 둔 상태이다.
  - **When**: 아이가 홈알바 화면에서 '완료'를 누르고, 부모 모드에서 해당 알바를 '승인'한다.
  - **Then**: 아이의 잔액이 2,000원 증가하고 `transactions`에 `type: 'deposit'`, `memo: '홈알바: 설거지하기'`로 기록된다.
